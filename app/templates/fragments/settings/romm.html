RomM Sync

Connecting to RomM

  1. Create a RomM Client API Token with roms.read and platforms.read scopes
  2. Enter the RomM address Shelf can reach, for example http://romm:8080
  3. Paste the rmm_… token and use Test
  4. If your browser uses another domain, set the Browser / Public URL below

What does sync do?

Selected RomM platforms are imported as Digital Games with RomM metadata and artwork. Physical Video Games stay separate and matching title/platform copies are linked.

Server-side address Shelf uses for API, metadata and cover traffic.
