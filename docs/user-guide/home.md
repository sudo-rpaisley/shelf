# Home

Shelf opens on **Home**, a collection overview. It is deliberately separate from **Browse**: Home answers “what is happening in my library?”, while Browse remains the place for searching, filtering, sorting and bulk editing.

Home shows:

- catalogue, owned and wishlist totals;
- items currently lent out;
- missing-cover count — items you have marked **Not available** in the
  [cover review queue](items.md#the-review-queue) are excluded, so this
  agrees with the same figure on Settings;
- the media types currently present in the collection;
- a media-type breakdown;
- recent additions;
- direct links to Browse, Series and Statistics.

Editors and administrators also get a **Scan item** shortcut. Viewers see the same read-only overview without mutation controls.

## Recently added

Browse up to **24** recent additions in one horizontal row, newest first. Swipe,
scroll, or use the previous/next buttons; nothing advances automatically. The
count describes items in the row, not how many fit on screen. **View all** and the
last **View more** tile open the complete collection.

Artwork keeps its original proportions. Short previews show two title lines and
one creator line; open an item's **Details** to read its complete title, credits
and type with a keyboard or touch. **Item size** fits more or fewer complete items
across without shrinking text; **Reset** restores the default. This setting lasts
only for the current page.

Without JavaScript, the row shows up to eight recent items. Item links,
**Details** and **View all** still work.

No new dashboard data is stored. The page is built from the existing catalogue, checkout and cover state each time it is opened.
